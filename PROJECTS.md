# 🛠️ Cybersecurity Projects to Build

> If you keep hearing you can't get a job because you have no experience, this takes that excuse away. These are real projects you can build, document, and put on your resume, beginner through advanced. Each one proves a skill a hiring manager actually cares about.

> 💡 The move: build it, write it up, put it on GitHub, and turn each project into a resume bullet (see [RESUME.md](RESUME.md)). Documenting it is what turns a weekend lab into proof.

**Jump to:**
[🟢 Beginner](#-beginner) · [🟡 Intermediate](#-intermediate) · [🔴 Advanced](#-advanced) · [🚀 Beyond Advanced](#-beyond-advanced)

---

## 🟢 Beginner

Learn the fundamentals by doing. Perfect first entries on a resume.

| Project | What it proves |
| --- | --- |
| **Analyze a PCAP** | You can read network traffic and spot what matters. |
| **Investigate Windows Event Logs** | You understand host telemetry and can trace activity. |
| **Basic Active Directory lab** | You know how the environment attackers target actually works. |
| **Wireshark traffic analysis** | Hands-on packet analysis, a core analyst skill. |
| **Phishing email investigation** | You can pull apart headers, links, and payloads safely. |

## 🟡 Intermediate

Now you are building and detecting, not just observing.

| Project | What it proves |
| --- | --- |
| **Wazuh or Splunk SIEM lab** | You can stand up logging and hunt across it. |
| **Write Sigma rules** | You can turn attacker behavior into portable detections. |
| **Create Sentinel detections** | Cloud-native detection engineering with KQL. |
| **Vulnerability scan + remediation report** | You can find issues and communicate the fix to a business. |
| **Basic malware analysis** | Static and dynamic triage in a safe lab. |
| **Build an incident-response playbook** | You can turn chaos into a repeatable process. |

## 🔴 Advanced

Portfolio pieces that look like the actual job.

| Project | What it proves |
| --- | --- |

## 🚀 Beyond advanced

The real unlock: stop doing tutorials and go solve something. Pick a problem that genuinely interests you, or a real annoyance you have, and build a tool or automation for it. It does not have to be perfect, and it does not matter if it is AI-assisted or "vibe coded." Shipping something real that solves a genuine problem beats another finished tutorial every time.

Where to find problems and challenges worth building around:

| Source | Why |
| --- | --- |
| **[TryHackMe](https://tryhackme.com)** | Endless guided scenarios you can extend into your own projects. |
| **[Hack The Box](https://www.hackthebox.com)** | Realistic targets that spark tooling and automation ideas. |
| **Threat Terminal** | Live threats and intel to build detection and enrichment projects around. |

And the goal to aim for, a real project of your own:

| Example | What it is |
| --- | --- |
| **[Enterprise Zapp](https://github.com/scottalt/Enterprise-Zapp)** | My own project. Proof that solving a real problem and shipping it is the whole point. |

> ⚠️ Only test and attack systems you own or have written permission to use. Build in your own lab.
