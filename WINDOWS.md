# 🪟 Free Windows Tools (IT & Security)

> The free tools I actually keep on every Windows machine I touch, as an IT and security engineer. Every one is free, and a few are the difference between a slow day and an easy one. The ⭐ marks the five in the video.

> ✅ **Always download from the official site linked here.** Tools this popular are heavily impersonated by fake download pages and malvertising.

## 🧰 System & internals

| Tool | What it does |
| --- | --- |
| ⭐ **[Sysinternals Suite](https://learn.microsoft.com/en-us/sysinternals/)** | The essential Windows internals kit: Process Explorer, Autoruns, Procmon, PsExec, TCPView. |
| ⭐ **[Microsoft PowerToys](https://learn.microsoft.com/en-us/windows/powertoys/)** | Free power-user utilities: FancyZones, PowerRename, Run, and more. |
| ⭐ **[Everything (voidtools)](https://www.voidtools.com/)** | Instantly search every file name on your drive as you type. |

## 🌐 Networking

| Tool | What it does |
| --- | --- |
| ⭐ **[Angry IP Scanner](https://angryip.org/)** | Open-source scanner that maps every device on your network in seconds. |
| **[Wireshark](https://www.wireshark.org/)** | The standard for capturing and analyzing network traffic. |
| **[PuTTY](https://www.putty.org/)** | Free SSH and serial client for remote access. |

## 💽 Disk, files & setup

| Tool | What it does |
| --- | --- |
| ⭐ **[Rufus](https://rufus.ie/)** | Create bootable USB drives for installs, recovery, and imaging. |
| **[7-Zip](https://www.7-zip.org/)** | Fast, free archiver that opens just about anything. |
| **[WinDirStat](https://windirstat.net/)** | See exactly what is eating your disk space, visually. |
