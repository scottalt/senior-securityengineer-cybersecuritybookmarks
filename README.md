## 🕵️ Recon & OSINT

Mapping attack surface, harvesting intel, and finding what's exposed before anyone else does.

| Resource | What it does |
| --- | --- |
| **[Shodan](https://www.shodan.io)** | Search engine for internet-connected devices and exposed services. |
| **[Censys](https://search.censys.io)** | Attack-surface search across hosts, certs, and services. |
| **[crt.sh](https://crt.sh)** | Certificate transparency search to uncover subdomains. |
| **[DNSdumpster](https://dnsdumpster.com)** | Free DNS recon and subdomain mapping. |
| **[ViewDNS.info](https://viewdns.info)** | Bundle of DNS, WHOIS, and reverse-IP lookup tools. |
| **[theHarvester](https://github.com/laramies/theHarvester)** | Emails, subdomains, and names from public sources. |
| **[OSINT Framework](https://osintframework.com)** | Categorized directory of OSINT tools for any lead. |
| **[Hunter](https://hunter.io)** | Find and verify professional email addresses. |
| **[Wappalyzer](https://www.wappalyzer.com)** | Fingerprint the tech stack behind any website. |
| **[Wayback Machine](https://archive.org/web)** | Historical snapshots of pages and deleted content. |
| **[Google Hacking DB](https://www.exploit-db.com/google-hacking-database)** | Dorks that surface exposed files and portals. |
| **[awesome-shodan-queries](https://github.com/jakejarvis/awesome-shodan-queries)** | Curated Shodan searches worth bookmarking. |
