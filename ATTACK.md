# 🎣 How Hackers Actually Get In

> I showed you [how to find almost anyone](OSINT.md) and [how to disappear](PRIVACY.md). This is the part in between: the exact ways attackers get into normal people's accounts, and how to slam every door shut. Phishing, text and phone scams, stolen passwords, and the defenses a senior security engineer actually trusts.

> ⚠️ **This is for recognizing and stopping attacks, not running them.** Only ever test systems and people that have agreed to it in writing.

## 🎣 Phishing and fake login pages

The number one way in. A convincing email and a fake login page, one click, and your password is theirs. Train your eye and report the ones you spot.

| Tool | What it does |
| --- | --- |
| **[Google Phishing Quiz](https://phishingquiz.withgoogle.com)** | Jigsaw's quiz that trains you to spot real phishing. |
| **[PhishTank](https://phishtank.org)** | Community database of known phishing URLs. |
| **[OpenPhish](https://openphish.com)** | Live feed of phishing sites active right now. |
| **[APWG Report Phishing](https://apwg.org/reportphishing/)** | Send phishing to the Anti-Phishing Working Group. |
| **[Report to CISA](https://www.cisa.gov/report)** | Official US channel to report phishing and incidents. |

## 📱 Smishing and vishing (text and phone scams)

Same trick, delivered by text or a phone call. "Your package failed to deliver." "This is your bank's fraud line." Report them and cut them off.

| Tool | What it does |
| --- | --- |
| **Forward scam texts to 7726** | 7726 spells SPAM, and it flags the sender with your carrier. |
| **[FTC Report Fraud](https://reportfraud.ftc.gov)** | Report scam texts, calls, and emails to the FTC. |
| **[FCC Complaints](https://consumercomplaints.fcc.gov)** | Report unwanted, spoofed, and robocall numbers. |
| **[Nomorobo](https://www.nomorobo.com)** | Block robocalls and spoofed caller IDs. |
| **[ITRC](https://www.idtheftcenter.org)** | Free help if a scam call already got your info. |

## 🔑 Stolen and reused passwords

One password reused from an old breach lets an attacker walk straight into your other accounts. This is credential stuffing, and it is automated.

| Tool | What it does |
| --- | --- |
| **[Have I Been Pwned](https://haveibeenpwned.com)** | Check your email against known data breaches. |
| **[Pwned Passwords](https://haveibeenpwned.com/Passwords)** | See if a specific password has already leaked. |
| **[Mozilla Monitor](https://monitor.mozilla.org)** | Ongoing alerts the moment you show up in a breach. |
| **[DeHashed](https://dehashed.com)** | Search breach data to see exactly what leaked about you. |

## 🔗 Check a link or file before you click

When something feels off, inspect it in a sandbox instead of opening it on your real machine.

| Tool | What it does |
| --- | --- |
| **[VirusTotal](https://www.virustotal.com)** | Scan a link or file against 70+ engines. |
| **[urlscan.io](https://urlscan.io)** | See what a URL actually loads, safely and remotely. |
| **[CheckPhish](https://checkphish.bolster.ai)** | Free real-time scanner for phishing and scam URLs. |
| **[Unshorten.It](https://unshorten.it)** | Expand a shortened link before you ever open it. |
| **[ANY.RUN](https://app.any.run)** | Detonate a suspicious file in an interactive sandbox. |
| **[Hybrid Analysis](https://www.hybrid-analysis.com)** | Automated malware analysis for sketchy attachments. |

## 🧪 Test yourself and your team

The best way to beat phishing is to practice it, on people who agreed to it. Authorized testing only.

| Tool | What it does |
| --- | --- |
| **[CanIPhish](https://caniphish.com)** | Free phishing simulator with built-in training. |
| **[Gophish](https://getgophish.com)** | Open-source framework for authorized phishing tests. |
| **[KnowBe4 Free Test](https://www.knowbe4.com/free-phishing-security-test)** | Free simulated phishing run for your organization. |
| **[SANS OUCH!](https://www.sans.org/newsletters/ouch/)** | Monthly plain-language security awareness newsletter. |
| **[Social-Engineer.org](https://www.social-engineer.org)** | The human-hacking side of attacks, explained. |

## ✅ Shut it down

The short list that stops the large majority of these attacks. Do these and you are a hard target.

| Tool | What it does |
| --- | --- |
| **[Passkeys](https://fidoalliance.org/passkeys/)** | Phishing-proof logins that replace the password entirely. |
| **[Bitwarden](https://bitwarden.com)** | A password manager kills reuse, the root of most breaches. |
| **[Aegis Authenticator](https://getaegis.app)** | App-based 2FA that beats SMS codes. |
| **[YubiKey](https://www.yubico.com)** | Hardware key, an unphishable second factor. |
| **[Google Security Checkup](https://myaccount.google.com/security-checkup)** | Review every device and app with access to your account. |
