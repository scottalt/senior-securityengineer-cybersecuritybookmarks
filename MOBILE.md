# 📱 Mobile Security Apps

> The security apps I actually keep on my phone. Turn the device in your pocket into a network scanner, a traffic analyzer, and a portable pentest platform. This is the Android loadout. iOS is coming.

> ⚠️ **For learning and authorized testing only.** Only scan and test networks and devices you own or have written permission to assess.

## 🤖 Android

### 📟 Terminal & pentest platforms

Turn your phone into a real Linux box and reach anything remotely.

| App | What it does |
| --- | --- |
| **[Termux](https://termux.dev/)** | Full Linux terminal environment for Android. |
| **[Kali NetHunter](https://www.kali.org/get-kali/#kali-mobile)** | Kali Linux mobile penetration-testing platform. |
| **[UserLAnd](https://f-droid.org/packages/tech.ula/)** | Run Linux distros without root. |
| **[ConnectBot](https://connectbot.org/)** | SSH into servers from your phone. |

> 🎥 New to NetHunter? Start with David Bombal's [YouTube walkthrough](https://www.youtube.com/watch?v=Lqu-G7sqClA).

### 📡 Network analysis & scanning

See exactly what's on the network and where the gaps are.

| App | What it does |
| --- | --- |
| **[Fing](https://www.fing.com/)** | Network discovery and device scanning. |
| **[Network Analyzer](https://techet.net/netanalyzer/)** | Scan networks, ports, DNS, and routes. |
| **[PortDroid](https://sec.stealthcopter.com/portdroid/)** | Port scanning and network utilities. |
| **[WiFiman](https://ui.com/download/app/wifiman)** | Wi-Fi and network analysis. |
| **[WiFi Analyzer](https://github.com/VREMSoftwareDevelopment/WiFiAnalyzer)** | Check channels, signal, and congestion. |

### 🔍 Traffic & API inspection

Capture and read what your device is actually sending.

| App | What it does |
| --- | --- |
| **[PCAPdroid](https://github.com/emanuele-f/PCAPdroid)** | Capture and inspect network traffic, no root required. |
| **[Reqable](https://reqable.com/)** | Inspect HTTP/S traffic and test APIs. |

### 🔐 Privacy, access & 2FA

Lock down your own device and reach your labs safely.

| App | What it does |
| --- | --- |
| **[Rethink DNS + Firewall](https://github.com/celzero/rethink-app)** | Block connections and filter DNS. |
| **[WireGuard](https://www.wireguard.com/)** | Fast VPN client for accessing labs securely. |
